# Plan 02: Authorized Project and Lifecycle APIs

## Objective

Protect project data by role, expose the exact UI contract, wire recent access, and add atomic platform-admin lifecycle operations.

## Response contract

`GET /api/projects` returns authorized rows only:

```text
{ projects: [{ id, name, templateId, templateVersion, status, role,
  publishedVersion, updatedAt, summary, unitCount, taskCount, stageCount,
  isRecent, lastAccessedAt }], recent: [same shape, max 4 active authorized] }
```

`GET /api/projects/:id/public` returns `{ project: metadata+role, snapshot }`; `snapshot.overallProgress` preserves null. Viewer contracts contain no draft pointer/version/content. Switcher uses active authorized rows.
