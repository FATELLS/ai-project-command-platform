# 当前结果

> 本文件只描述已经完成并通过验证的结果。规划目标见 `.planning/`。

## 已完成

- 建立独立项目、需求、架构、路线图、AI 契约和迁移基线。
- 建立 Node.js 24.15+ 与内置 SQLite 数据底座，包含校验和、WAL、外键、索引和事务迁移。
- 建立项目、模板、用户、成员、版本、模块、作战单元、路线、闭环、任务、依赖、战线和提案元数据表。
- `published` 和 `draft` 使用独立版本图；项目指针受归属和层级约束。
- 建立任务 ID、父子关系、前置依赖、跨单元关系和循环的确定性校验。
- 已将 `xugu-agentic-group` 脱敏 v4.2 夹具导入 SQLite，保留 7 个作战单元、29 项任务、6 个节点、2 个闭环和 4 条公司战线。
- 导入为原子、幂等操作；导出与原夹具深度语义等价。
- 已实现项目列表、项目发布快照、项目草稿快照和虚谷旧入口兼容读 API。
- 统一验证包含 12 项数据库、迁移、任务图、项目隔离和 API 测试，以及临时数据库/API 冒烟。
- 验证会确认参考应用的 HEAD、Git 状态和脱敏种子哈希未变。
