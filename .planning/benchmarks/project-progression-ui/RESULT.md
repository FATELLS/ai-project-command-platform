## 运行中发现并修复

1. 正式启动入口没有启动材料处理 worker，UI 上传后会停留在等待状态。已在服务进程启动串行 worker，并补启动恢复、错误退避和优雅停止。
2. XLSX 提取器无法识别带 XML namespace 前缀的 `<x:c>`、`<x:v>`、`<x:si>`。已兼容前缀并补直接字符串测试。
3. XLSX 证据定位器只显示工作表，遗漏单元格地址。已改为“工作表 · 单元格 A1”。
4. UI 声称支持 MD、CSV、JSON、YAML，但上传门阀只允许 TXT。已统一前后端格式策略和 UTF-8 文本魔数校验。
5. 重复材料等门阀错误使用实际小写代码时缺少中文映射。已补齐重复、项目条数、容量和并发提示。
6. 生成能力接口没有返回材料 readiness，生成面板会显示“待诊断”。已把服务端 readiness 放入材料能力 envelope。
7. 生成面板曾因材料总证据块超过 48 而在前端禁用按钮，但服务端本来会安全截断到 48。已移除错误的前端额外禁用条件并补回归。
8. 首次真实 DOCX 生成先后暴露 provider 超时、思考输出导致非 JSON、提示词缺少内部字段契约三类问题；失败任务均未创建提案、草稿或发布副作用。现已增加 5 分钟有界超时、可选 `reasoning_effort=none` 和精确输出契约，BM-08 复跑一次成功。
