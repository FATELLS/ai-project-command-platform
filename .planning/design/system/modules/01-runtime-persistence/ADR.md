# ADR S-01：虚谷作为唯一事务与持久化边界

状态：`accepted`
日期：2026-08-02

## 决策

平台 1.0.0 只支持虚谷数据库。源码、测试、迁移、备份、发布和 UI 隔离环境都连接真实虚谷实例，不维护第二后端。

虚谷 Docker 镜像与目标架构原生驱动随 portable 产物交付。默认由平台生命周期管理器管理专用容器；共享数据库仅在显式 external 模式下连接。

## 原因

- 产品边界要求虚谷随系统启停、备份和恢复。
- 双后端会让 SQL 方言、事务、迁移和测试长期分叉。
- 只有真实虚谷测试才能发现字符集、CLOB、别名类型和驱动回调行为。

## 影响

- Node.js 固定在原生驱动支持的 20.x ABI 范围。
- v1.0 发布目标限定 ARM64。
- 所有自动化数据库夹具必须使用独立容器、端口和 volume。
- 数据库错误不得通过兼容分支静默降级。
