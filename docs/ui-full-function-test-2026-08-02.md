## 本轮发现并修复

- 首次虚谷 volume 初始化可能超过 180 秒：启动与 E2E 等待窗统一为 420 秒，失败 Worker 立即终止。
- 原生驱动 callback 与同步仓储契约不一致：增加独占 Worker 桥接，完整消费查询回调。
- 数值版本列重命名为同表字符串 `id` 时发生结果解码冲突：改用 `currentVersionId` 明确别名。
- 生成链路的强制断线重连会干扰 CLOB 结果收尾：移除非必要重连，提案在明确事务中保存。
- 提案审核项不再依赖未启用的触发器，保存提案时显式创建 review item。
- 项目搜索与移动端断言等待真实卡片加载；资料用例明确选择虚谷项目，消除排序耦合。
- 项目资料导航改用稳定项目路由，避免重复入口文本导致选择器歧义。
- Node 20 下 provider deadline 改用有引用的 `AbortController` 定时器，消除测试被提前取消。
- `file-type` 升级到 `21.3.4`，修复输入解析 DoS 公告。
