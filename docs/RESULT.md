# 当前结果

> 本文件只描述已经完成并通过验证的结果。规划目标见 `.planning/`。

## 已完成

- 建立独立项目、需求、架构、路线图、AI 契约和只读迁移基线。
- 建立 Node.js 24.15+ 与内置 SQLite 数据底座，包含迁移校验和、WAL、外键、索引和事务。
- 项目、模板、用户、成员、版本、模块、作战单元、路线、闭环、任务、依赖、战线和提案元数据使用独立实体。
- `published` 与 `draft` 使用独立版本图；项目指针受归属和层级约束。
- `xugu-agentic-group` 脱敏 v4.2 已迁移，保留 7 个作战单元、29 项任务、6 个节点、2 个闭环和 4 条公司战线，导出与夹具语义等价。
- 密码使用带盐 scrypt；会话 token 只以 SHA-256 摘要保存，浏览器使用 HttpOnly、SameSite=Strict Cookie。
- 会话有 30 分钟空闲与 8 小时绝对过期，写操作使用内存 CSRF token，登录有统一错误与 IP 窗口限流。
- 建立平台管理员、项目管理员、项目编辑者、查看者角色；项目列表和详情按 `projectId` 与成员权限隔离。
- 建立授权项目搜索、状态筛选、排序、最近访问前四、项目切换和只读发布态概览。
- 平台管理员可事务性创建、编辑、归档和恢复项目；每次生命周期变化写入追加式审计事件。
- 创建项目生成相互独立的空发布版/草稿版，并授予创建者项目管理员角色；不写虚构完成率。
- 提供本地语义 HTML/CSS/JavaScript 平台 UI，含登录、项目首页、项目壳和可访问管理对话框；桌面端已按 Xugu 稳定界面修正为 76px 白色顶部导航、暖色指挥背景、左右双栏 Hero 和横向章节卡片，无深色 SaaS 侧栏。
- 项目详情的顶部标题、Banner、当前状态提示、事实标签、模块标签和新建摘要已由项目模板/术语配置驱动；`xugu-agentic-group` 作为首个 Xugu Agentic Group Schedule 作战项目保留作战语言，标准项目使用团队、任务、里程碑和交付物语言。
- 提供不可变、版本化的 `campaign-map-v1@1.0.0` 与 `standard-project-v1@1.0.0` 目录；模板定义受控主题、术语、字段、状态、必需模块、顺序、Schema 和默认视图。
- 服务端注册 Overview、Units、Roadmap、Task Network、Gantt、Outcomes、Risks、Metrics、Materials 九种模块；未知类型、Schema、视图、关系和可执行资产失败关闭。
- 浏览器通过仓库内固定 DOM/SVG renderer map 展示九类模块；项目配置不能提供 HTML、CSS、JavaScript、SVG 或组件路径。
- 模块配置采用完整列表事务，只写 `draft`；Overview 固定启用，保存草稿不改变 `published` 导航或删除事实，查看者无配置入口。
- Xugu Roadmap/Task Network/Gantt/Outcomes 保留 6 阶段、2 闭环、4 战线、29 任务和 28 有日期/1 待排期语义；标准夹具独立显示 3 团队、7 任务、4 里程碑、2 工作流及线性/依赖列表/泳道变体。
- Materials 模块已成为固定项目材料工作区，提供服务器权威配额、流式文件上传、人工材料、持久台账、状态筛选、处理重试、更新意图和独立问答授权。
- 摄入层校验文件大小、魔数/MIME、压缩路径与展开上限、容量、频率和并发；可选扫描器配置为必需时不可用即失败关闭，失败流不会留下孤儿对象。
- 证据处理支持人工文本、TXT、JSON、CSV、DOCX、PPTX、XLSX，以及受限 PDF/图片子进程适配器；证据保留段、页、幻灯片、单元格、边界框或 OCR 定位和稳定摘要。
- 项目问答使用同一 SQLite 事务域内的项目/授权/当前代际过滤与 FTS5 检索；provider 默认禁用，证据视为不可信文本，输出只接受 allowlist 引用，无证据或 provider 不可用时诚实拒绝。
- Chat 与未来 Generation 使用独立持久配额和全局有界 provider 并发；Phase 4 问答只读，不写 proposal、draft 或 published。
- 六类更新模板以不可变 `id@version` 目录约束会议纪要、项目计划、进度汇报、指标数据、成果归档和新项目材料可生成的模块、操作、字段与高影响证据要求。
- 生成任务锁定当前项目发布版本、同模板材料、当前提取代际、证据 ID/哈希和 Schema；支持幂等创建、失败重试 lineage、stale 基准、attempt、Token 和版本化成本记录。
- generation 使用独立服务端 provider 配置、4 次/分钟与 100 次/日预算，并与 chat 分账；无配置时材料和既有提案仍可浏览，提交明确禁用。
- `change-proposal-v1@1.0.0` 只接受有界结构化增量；服务端重新校验 envelope、项目/证据归属、模板字段、目标、语义、日期、依赖 DAG、重复与版本冲突，非法输出最多修复一次后失败关闭。
- 仅完整验证通过的提案、变更项和证据关系在一个事务中保存；所有生成成功、失败和重试路径均无权修改 `draft`、`published` 或项目版本指针。
- 固定 Materials renderer 提供 Xugu“作战更新提案”和标准“项目更新提案”工作区、任务详情、验证结果、字段差异、置信度/警告与精确证据回跳；当前无审核、合并、发布或回滚控件。
- 直接刷新项目路由、会话过期、退出后 Back、未知/越权统一 404 已通过真实浏览器验证。
- 统一验证通过 120 项自动化测试，以及 Phase 3–5 共 46 个真实浏览器阻断用例；13 张桌面/平板/手机证据均通过 SHA-256 与尺寸机检。
- 验证确认参考 Xugu 应用的 HEAD、Git 状态和脱敏种子哈希未变。
