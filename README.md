# AI 项目作战管理平台

独立的新平台项目，用于管理多个项目；每个项目可以包含多个作战单元或团队。平台接受纪要、数据、计划和文件等多样输入，通过 LLM 生成带来源的结构化变更提案，经人工审核后更新路线、甘特、任务、成果和风险模块。

## 当前状态

项目已完成初始化和路线图，尚未实现可运行平台。现有“虚谷 AI 转型促进作战地图”保持不变，并作为首个迁移项目和回归样本。

## 项目原则

- 平台管理项目，项目管理多个作战单元。
- 输入可以多样，呈现结构保持稳定。
- LLM 生成结构化数据提案，不生成或执行页面代码。
- 提案必须携带项目、基础版本和来源证据。
- 管理员审核后进入草稿，发布仍由人工完成。
