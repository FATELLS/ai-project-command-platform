# Phase 6 Context：差异审核、发布、权限与运营

状态：`accepted`
日期：2026-07-18

## Locked scope

- 项目管理员和平台管理员按模块审核 pending `ChangeProposal`，逐项接受、驳回或编辑，支持整模块接受。
- 每项差异显示发布基准原值、建议值/编辑值、证据、语义、置信度、警告和决定人/时间。
- 只有全部项目项已决定且至少一项接受时，才能把接受项在单事务中合并为新的 immutable draft version；失败不改变 draft pointer。
- 发布必须从当前 draft 生成新的 immutable published version，并立即建立与之相同的新 draft 基线；不能从 proposal 直接发布。
- 回滚只允许到当前 published 的直接上一版本，更新指针并建立新的 draft 基线；发布和回滚都追加审计。
- 编辑者可读取审核/预览，查看者维持只读已发布与已验证提案；审核、合并、发布和回滚只允许项目管理员/平台管理员并要求 CSRF。
- 提供 SQLite 一致性备份/离线恢复、脱敏项目导入导出、审计查询、评估数据集、跨项目安全测试和 Xugu UAT。
- 固定九模块 renderer 继续负责预览；项目/材料/提案不能提供代码、HTML 或组件路径。

## Non-goals

- 不做无审核自动发布、实时多人锁、任意历史分支合并、跨项目复制提案或多服务器部署。
- 不让恢复命令在线覆盖正在运行的数据库；恢复要求显式源文件、离线校验与自动保留旧库副本。
