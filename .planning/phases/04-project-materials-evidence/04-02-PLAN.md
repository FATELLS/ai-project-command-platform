# Plan 02: Bounded Extraction and Locatable Evidence

## Objective

Convert supported project materials into bounded, source-locatable evidence using recoverable jobs and honest degradation.

<task type="auto">
  <name>Task 1: Implement typed extractors</name>
  <files>src/materials/extractors, test/fixtures/materials, test/material-extraction.test.mjs</files>
  <action>Provide plain text/manual, OOXML, PDF and image adapters. Emit normalized blocks with deterministic order and paragraph/page/slide/sheet-cell/image/OCR locators. Bound entries, expanded/text bytes, blocks, subprocess time/memory/output and OCR confidence; never execute macros, links or embedded content. Missing Poppler/Tesseract returns a stable capability state.</action>
  <verify><automated>node --test test/material-extraction.test.mjs</automated></verify>
  <done>Every supported small fixture yields the expected escaped text and locator; malformed/unsupported/dependency-failed samples never become ready.</done>
</task>
