# Phase 4 Context: 项目材料与证据层

状态：`accepted for planning`
日期：2026-07-18

## 阶段目标

把项目文件安全摄入为按项目隔离、可精确定位、可授权检索的证据，并提供只读、带来源、证据不足时明确拒答的项目内问答；整个阶段不得产生或执行项目变更。

## 锁定方向

- 材料、处理任务、证据块、问答配额与审计全部携带并服务端校验 `projectId`；对象 ID 不得成为越权读取通道。
- 原件和处理产物存放在 webroot 与 Git 工作区之外；SQLite 保存元数据、状态、授权、定位和 FTS5 索引。
- 上传采用流式 staging 与两阶段提交。授权、CSRF、请求体、容量、类型、魔数、摘要重复、频率、并发及 OOXML 解包门阀全部通过后，才登记可处理材料。
- 首版支持文本、PDF、DOCX、PPTX、XLSX、PNG/JPEG/WebP；不支持或依赖缺失时必须给出稳定状态和可操作说明，不得伪造已提取内容。
- 页、段、表格、幻灯片、工作表/单元格和图片/OCR 坐标使用类型化 locator；每个问答引用必须指向实际检索到且当前仍获授权的证据块。
- 检索使用 repository-local deterministic 2-step RAG v1：SQLite FTS5、稳定排序、受控上下文和最多一次无工具的 OpenAI-compatible 模型调用。
- 模型 provider 由服务端环境配置；默认 `disabled` 不影响平台启动、材料处理和检索，测试 `fake` 只能依赖注入且无需公网或密钥。
- 问答只读当前项目的 `published` 事实和已明确启用问答的 ready 材料；provider 没有工具、仓储、SQL、网络浏览或任何写入能力。
- 更新模板选择在本阶段只记录材料后续用途意图；不得生成 `ChangeProposal`、修改 draft、审核、合并或发布。

## 第一版安全与容量基线

- 单文件 200 MiB；每项目最多 100 个活动材料和 300 MiB 存储产物；每用户/项目每分钟最多 6 次上传尝试、1 个并发上传。
- Multipart 只接受 1 个文件、最多 4 个字段/8 个 parts；文件名只作为净化后的展示文本，实际存储使用服务端生成 ID。
- OOXML 最多 2,000 个 ZIP entries、80 MiB 展开内容、100:1 压缩比，拒绝绝对路径、`..`、符号链接和重复规范路径。
- 单材料最多 10 MiB 提取文本/20,000 个证据块；处理任务使用有限并发、超时、租约和幂等恢复。
- 问题最多 1,000 字符；每来源+用户+项目每分钟 12 次、平台每日 300 次、全局最多 2 个模型调用。chat 与未来 generation 使用独立权限和配额账本。
- 所有限制由服务端能力/配额 envelope 返回，浏览器不自行推断。部署可降低这些默认值而不修改 UI 文案。

## 依赖与降级取舍

- Poppler 与 Tesseract 可用于 PDF 定位和 OCR；运行时启动探测能力，缺失时材料进入诚实的依赖缺失/需人工说明状态。
- ClamAV 和 CDR 不是本次内部单机验收的强制运行依赖，但预留隔离扫描 hook 与能力告警；一旦部署配置为必需，扫描不可用必须 fail closed。
- qpdf 为可选 PDF 结构预检；首版以 `pdfinfo`/Poppler 错误和严格超时/资源门阀降级。
- provider 保持 OpenAI-compatible/GLM 中立，不把具体模型或易变价格写入项目材料 Schema；上线时由部署配置和能力 profile 决定。

## 验收口径

- 两个项目上传同名及相同摘要材料时，台账、原件、证据、搜索和问答均不串项目。
- 恶意扩展名/MIME/魔数、超限、重复、ZIP bomb/path traversal、处理中断和并发竞争不会留下孤儿文件、错误计费或可检索脏证据。
- 支持格式产生可导航的页/段/表/图定位；低置信 OCR、空证据、未授权来源和无 provider 都显示确定、可测试的不足/不可用状态。
- fake provider 的问答只允许引用本次检索 allowlist，恶意材料中的 prompt injection 不能改变项目、授权、工具或输出契约。
- Xugu 与标准项目在 1440×900、1024×768、390×844 三视口完成材料台账、上传反馈、证据查看和问答验收，保持 Phase 3 项目页视觉基线。

## 明确不做

- 从材料生成、校验或重试 `ChangeProposal`；
- 提案差异审核、草稿合并、发布或回滚；
- 浏览器端文件解析、向量化、模型调用或密钥保存；
- 任意 HTML/CSS/JavaScript 页面生成；
- 将问答历史或模型摘要自动写回项目事实。
